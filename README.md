# Sign Arc Bee

A playful **Arc Network wallet and ecosystem feedback interface** built around a mobile-first Web3 interaction flow.

## Product concept

Sign Arc Bee combines a wallet-oriented dashboard with an Arc community feedback surface. It is designed as a compact experiment in onboarding, account state and ecosystem participation.

## Interface features

- Arc Network themed wallet dashboard
- Simulated secure wallet connection flow
- Balance and address presentation
- Discord + X feedback inputs
- Responsive single-screen mobile layout
- Clear success/error interaction states

## Stack

- Next.js / React
- JavaScript
- CSS-in-JS / responsive UI
- Wallet-oriented product UX

## Development

```bash
npm install
npm run dev
```

## Security note

The current interface contains simulated wallet state for demonstration. Never request, store or expose seed phrases/private keys in a frontend application.
